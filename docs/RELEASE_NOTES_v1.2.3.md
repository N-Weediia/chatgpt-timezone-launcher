# v1.2.3 — 界面更新

- 重新整理启动模式、出口检测、运行状态和 Codex 限额，支持浅色、深色和窄窗口布局。
- 手动输入或选择时区时自动切换到手动模式，限额剩余百分比和重置详情更加清晰。
- 保留重复启动时唤醒已有窗口、最小化恢复和关闭到托盘功能。
- 通过 26 项自动化测试和发布 EXE 的启动、单实例及窗口恢复检查。

## 下载与更新

下载 `ChatGPT-TimeZone-Launcher-v1.2.3-win-x64.exe`，适用于 Windows x64，无需安装 .NET。更新前请先从托盘退出旧版启动器，再替换原 EXE。

下载后的 SHA-256 校验值见 `SHA256SUMS-v1.2.3.txt`。
