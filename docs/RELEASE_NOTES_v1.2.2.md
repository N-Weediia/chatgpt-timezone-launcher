# v1.2.2 — 单实例与窗口唤醒修复

修复启动器已经运行或隐藏到托盘后，再次双击程序或快捷方式会打开第二个启动器的问题。

- 再次启动时显示并前置已有窗口；最小化和隐藏到托盘的窗口都可以恢复。
- 恢复时保留窗口原有的最大化状态；不同目录下的新版 EXE 也会共用同一实例。
- 通过 23 项自动化测试，以及发布 EXE 的并发启动、窗口恢复和退出后重新启动检查。

## 下载与更新

下载 `ChatGPT-TimeZone-Launcher-v1.2.2-win-x64.exe`，适用于 Windows x64，无需安装 .NET。

更新前请先从系统托盘退出旧版启动器，再用新版替换原 EXE。旧版进程不具备单实例唤醒功能，继续运行时无法与新版共享窗口。

下载后的 SHA-256 校验值见 `SHA256SUMS-v1.2.2.txt`。
