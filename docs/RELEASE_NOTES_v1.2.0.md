# v1.2.0 — 界面、托盘与 Codex 限额

## 更新内容

- 启动 ChatGPT 后实时显示进程状态，并尝试自动将主窗口切到前台。
- 重构主界面为响应式表格布局，窗口缩放时底部操作按钮保持在可见区域内。
- 支持点击右上角关闭按钮隐藏到系统托盘；托盘菜单可以显示窗口或完全退出。
- 新增限额面板，显示 Codex 5 小时窗口和 7 天窗口的已用/剩余百分比、北京时间重置时间和倒计时。
- 支持每 60 秒自动刷新、手动刷新，以及重置前 10 分钟的托盘提醒。

## 数据与隐私

启动器只读取本机现有的 Codex 登录文件 `.codex\\auth.json` 中的访问令牌，并仅向 `https://chatgpt.com/backend-api/wham/usage` 发送授权请求。令牌不会写入启动器配置、日志或仓库；限额结果只保存在内存中，关闭启动器后不保留。

## 验证

- 自动化测试：23/23 通过。
- 发布 EXE：全新配置和损坏配置的隔离启动检查通过。

## 兼容性边界

限额接口属于 Codex 客户端使用的账户接口，返回字段或登录文件位置未来变化时，启动器会显示读取失败并允许手动重试，不会猜测限额或重置时间。
